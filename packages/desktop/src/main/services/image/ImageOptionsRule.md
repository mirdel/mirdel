1. 统一核心参数（默认就展示）
* prompt
* 参考图/编辑图
* 比例（aspectRatio）
* 尺寸/清晰度档位（把 size / imageSize / resolution 归一）
* 数量（支持时才显示）
* seed（可放到“高级”）

2. 统一扩展参数（放高级设置）
* 质量档位（把 quality、fast/standard/ultra 归一成统一枚举）
* 风格（仅当多家都能映射时）

3. 特殊参数（仅小众且确有价值时才展示）
* 只有单一供应商支持、且对结果有明显影响的参数
* 其余工程型参数（response_format 等）全部隐藏并写死

建议的“是否升为统一参数”判断标准：
* 用户能感知结果差异
* 至少 2 家主流供应商可映射
* 语义稳定，不会“同名不同义”严重误导
* 能给出可用默认值
