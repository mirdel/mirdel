# Changelog

All notable user-facing changes should be documented in this file.

This project follows a simple versioned changelog format. Each release section
should match the desktop app version in `packages/desktop/package.json`.


## 0.1.0 - 2026-05-15

### Added

- Initial desktop release workflow for macOS and Windows builds.

### Changed

- Desktop release assets are published from tag builds.

### Fixed

- Stabilized CI packaging across macOS arm64, macOS x64, and Windows x64.
